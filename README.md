# Bookmark Manager

A browser-based CRUD application for saving and managing favorite websites. Bookmarks are validated and persisted in local storage so they remain available after a page refresh.

## Features

- Add website names and URLs
- Validate site names and URL formats
- Open saved websites in a new tab
- Delete individual bookmarks
- Persist data with the Local Storage API
- Responsive Bootstrap interface

## Built With

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Local Storage API

## Run Locally

~~~bash
git clone https://github.com/MohamedSamirMoussa/Bookmark.git
cd Bookmark
~~~

Open index.html in a browser. No dependencies need to be installed.

## Notes

This is a client-side learning project. Saved bookmarks belong to the current browser profile and are not synchronized to a server.
